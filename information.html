My Terraform Journey

Terraform · HCL · AWS · github.com/devops-aftab/my-terraform-journey

My Terraform Journey is the repository where I keep everything I learn about infrastructure as code. Instead of clicking resources together in the AWS console, each piece of infrastructure is written in HashiCorp Configuration Language (HCL) and kept in Git, so it can be reviewed, repeated and rebuilt from scratch.

Most of the code is organised into reusable modules. A module describes something like a network once, and each environment calls it with its own variables. That keeps development and production consistent without copying code between folders. A large part of the repo is also notes on state management: what the state file is, why it should never be edited by hand, and how remote state lets more than one person work on the same infrastructure safely.

What's inside

  • Reusable modules for networking, security groups and compute
  • Separate configurations per environment, driven by variables
  • Input variables, outputs and example .tfvars files
  • Notes on local and remote state, locking and drift

Terraform tip

Save your plan with terraform plan -out=tfplan and then apply that file. What gets created is exactly what you reviewed, even if the code changes in between.

Run terraform fmt and terraform validate before every commit. They catch most small mistakes in seconds.
